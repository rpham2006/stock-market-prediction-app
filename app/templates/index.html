How it works

  1. Fetch & store. A year of daily OHLCV bars per ticker, written to a database keyed on (symbol, day) so refreshes never duplicate rows.
  2. Build features. 13 technical inputs — trailing returns, distance from moving averages, realised volatility, RSI, intraday range position, volume ratio — all computed only from data known at that day's close.
  3. Fit & validate. Ridge regression, scored walk-forward: every prediction is made using only the days before it, then compared against "tomorrow equals today."
  4. Report honestly. If the model doesn't beat that baseline, the page says so in plain English instead of showing a confident number.
